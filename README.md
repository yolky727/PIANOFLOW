# PIANO FLOW 2.0

面向 iPad 的音频扒谱与和弦练习网站。请解压后上传 dist 内全部内容到原 piano-flow GitHub 仓库根目录（index.html 与 model 文件夹同级），覆盖旧文件。无需构建或 API 密钥。GitHub Pages 发布后在 Safari 打开网址。

## 真实扒谱
录音或导入音频，选择起止位置（每次最多 60 秒），点击开始真实扒谱。Spotify Basic Pitch 模型在浏览器内分析真实音频，模型文件已包含，音频不会上传。分析时保持页面打开。建议先用 10–30 秒清晰钢琴独奏；处理速度取决于设备。
识别结果可试听、在音符表校正、撤销、导出 MIDI 和 MusicXML。速度手动设置，五线谱使用八分音符量化；中央 C 上下分成高低音谱表，并非自动分辨左右手。MIDI 保留识别时间，MusicXML 使用量化时间。
这是自动识别的初稿，复杂混音、密集和弦、踏板混响可能出现错漏；没有承诺无误扒谱。当前按片段处理长曲，不自动分析整首混音歌曲，也不执行去伴奏。

## 和弦练习
20 种类型、12 根音，支持原位与转位。紫色琴键显示组成音和八度；整体试听与分解试听。练习模式隐藏答案，点选组成音，再检查漏音和多音。也可试听 ii–V–I。
页面使用统一等音命名，因此某些音名与严格乐理拼写不同（如减七和弦的重降音）；音级公式给出理论关系。真实钢琴可以看键位跟练，但目前不通过麦克风判定和弦对错。

## 保存
谱面音符自动保存在当前浏览器，JSON 可导出恢复。原音频不持久保存、不包含在备份中。清除浏览器网站数据会清除本地项目。请保留原始音频文件。

## 验证与限制
已完成打包检查，并用 440 Hz 合成音测试实际模型推理。未在用户的 iPad Safari 设备实测；浏览器性能和麦克风权限仍需在设备上确认。录音必须在 HTTPS 网页操作。
