# PIANO FLOW 2.1
解压后选中全部文件，上传到原仓库根目录。所有文件均在同一层，不需要创建 model 文件夹。model.json 与 group1-shard1of1.bin 必须和 index.html 同级。旧 model 文件夹可保留。

谱面：根据同一时刻音群跨度、音域和前后移动估计左右手，可在音符表手动指定。分手是估计，无法确定演奏者真正使用哪只手。支持八分/十六分网格、第一拍偏移、跨小节延音与和弦内部不同音长。重复音高的延音在下一次击键处结束，避免同音重叠。MusicXML 按网格输出，MIDI 和试听保留原始识别时间。拍号目前固定 4/4；不支持自动变速、三连音或自动调号。

识别仍使用 Basic Pitch，本次没有更换识别模型或承诺提高音高准确率。密集和弦、踏板、混响、多人合奏仍可能产生错漏；请用清晰钢琴独奏，从短片段开始，调整阈值并校正音符。每次最长 60 秒。

和弦：30 种和弦/排列，按基础、七和弦、爵士扩展、变化和弦和常用排列分类；包含 13、7♯11、7♭13、6/9、maj7♯11、9sus4、shell 与无根音排列。无根音排列应结合低音演奏，不适合直接当作完整独奏和弦。键盘使用统一等音拼写，音级公式保留理论关系。

项目自动保存在浏览器；音频不持久保存。保持 JSON 备份。原音频未包含在项目备份中。音色为本地合成钢琴，不是真实采样。

已完成语法、构建及谱面小节时值/延音和左右手典型样例检查；尚未在你的 iPad 实测。
